# Stream Clip Starter Templates

Free, copy-and-edit templates for turning your own streams into short vertical clips, or for editors who cut clips for a streamer with permission.

## What's in the repo

| File | What it is |
|---|---|
| `rights-log.csv` | One row per clip: who is on screen, whether they agreed, music, game policy, sponsor terms. One labelled example row, which you delete. |
| `clip-permission-one-page.md` | A plain-language one-page permission note between a streamer and an editor. |
| `clip-qc-checklist.md` | A 10-point check to run before a clip goes out. |
| `hook-sampler.csv` | 24 short hook lines (two for each of 12 moment types), some with `[blanks]`. |

## How to use it

Download or fork the repo, open the CSV files in any spreadsheet app, and edit the Markdown files in any text editor. Use only footage you own or have permission to use.
